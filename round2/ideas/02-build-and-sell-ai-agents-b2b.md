# Build and Sell Custom AI Agents to SMBs

## Summary
Develop and sell purpose-built AI agents (lead qualification, inventory, real estate ops) to small/mid-market businesses on retainer. Agencies are charging $40K-$80K for builds plus $1.5K-$3K/month maintenance in 2026.

## Speed to first dollar
2-4 weeks from outreach to first deposit if you focus on one vertical and one outcome.

## Startup cost
Low-medium. $50-$300/month (LangGraph/CrewAI/n8n, OpenAI/Anthropic API, vector DB, Cal.com).

## Skills needed
Prompt design, basic Python or no-code agent frameworks, API integration, sales/discovery calls.

## Income potential
$2,000-$15,000/month part-time (one to three SMB retainers); productized marketplace agents can add $20-$100/month per user passively.

## How to start
- Pick one operational outcome ("save 10 hrs/week qualifying leads"), not "an AI agent."
- Build a vertical demo (e.g., HVAC contractor inbound triage) and record a 3-min Loom.
- Cold-email 30 owners per day in that vertical; offer a $2K pilot + $1.5K/month management.
- Ship in 2 weeks, capture metrics, raise prices on next client.
- Later: list a templated version on aiagentstore.ai or Gumroad as passive SKU.

## Why this is different from anything in round 1
Round 1's "AI workflow automation consulting" sold Zapier/Make automations; this sells autonomous, multi-step agents with memory and decision-making, priced as a SaaS-like retainer per outcome rather than per workflow.
