How to play 🐝

Tap digits in the honeycomb to build an addition that equals one of the three target sums at the top.

  • Every sum must include the yellow center digit.
  • Use each digit at most once per equation. Minimum length 2.
  • Solve sums within 10s of each other to build a combo chain (×2, ×3, ×5).
  • The 🐝 Bee target has just one secret solution using all 7 digits. Worth a big bonus.
  • Keyboard: 1–9 add digits, Enter submit, ⌫ delete, Space shuffle.

A new puzzle each day. Same puzzle for everyone.
