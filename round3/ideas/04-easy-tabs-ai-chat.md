# PromptStash - Chrome Extension for AI Power Users

## One-line pitch
1Password for AI prompts: a Chrome extension that organizes, versions, and one-click-injects prompts across ChatGPT, Claude, Gemini, and Perplexity.

## Target user
Power users of LLM chat tools - product managers, marketers, lawyers, devs - who run 50+ chats/week and copy-paste prompts from Notion or Apple Notes today.

## Core feature (v1)
Sidebar that detects which chat tool you're on, shows a searchable prompt library (folders, tags, variables), and inserts with one click. Sync across devices, version history, team shared folders.

## Distribution wedge
Chrome Web Store (organic - same wedge that put Easy Folders at $3.7k MRR in 6 months). Plus launch on r/ChatGPTPro, r/ClaudeAI, r/PromptEngineering, and Product Hunt. Hit "AI tools" category top.

## Pricing model
Free for 25 prompts; $7/mo or $59/year for unlimited + sync + team features. $19/seat for teams.

## Path to $10k MRR in 60 days
1,500 paid users at $7 = $10.5k MRR. Easy Folders' actual growth curve hit 50k installs in 90 days; 3% conversion = 1,500. Realistic with PH launch + 3 niche subreddit posts.

## Build effort
10-12 days. Manifest V3 extension, Supabase backend, Stripe.

## Tech stack suggestion
React + Plasmo (extension framework) + Supabase + Stripe.

## Why now
ChatGPT alone hit 800M weekly active users in 2025; Claude and Gemini added another 200M. No native cross-tool prompt manager exists. Easy Folders proved exactly this distribution motion works ($42k revenue in 6 months from a smaller niche - ChatGPT folders).

## Defensibility
Chrome Web Store rankings, team workspaces create lock-in (admin invites coworkers), and DOM-injection scripts per platform require ongoing maintenance that copycats consistently underestimate.
